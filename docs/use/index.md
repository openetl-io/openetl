---
title: Use the console
description: Choose a console task for checking data freshness, syncs, incidents or connections.
---

Use the console to check the data that your team depends on. You do not need YAML or a terminal for these checks.

If you are new to the console, [sign in](./sign-in.md). Ask your administrator for the console address and a password link.

| Your task | Guide |
|---|---|
| Check whether your data is current | [Check data freshness](./freshness.md) |
| Find why data is late or a pipeline failed | [Review incidents](./incidents.md) |
| Inspect a run or its log | [Inspect and control syncs](./syncs.md) |
| Find missing rows or column values | [Inspect held and quarantined data](./held-data.md) |
| Test a connection before data moves | [Check connections and pipelines](./checks.md) |
| Inspect connected systems | [Inspect connections](./connections.md) |
| Find which actions your role permits | [Console settings and permissions](./access.md) |
| Inspect a SQL transform | [Inspect SQL transforms](./sql.md) |
| Use a terminal for these tasks | [Console tasks with the CLI](./cli.md) |

[Concepts](../get-started/concepts.md) defines the terms used in the console.
