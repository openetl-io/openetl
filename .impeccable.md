## Design Context

### Users

Data and platform engineers evaluating OpenETL on GitHub. They need to understand its purpose, operating model, and efficiency before trying a pipeline.

### Brand Personality

Direct, capable, open. The README header should convey confidence and engineering care. The user selected a bold technical direction using the existing logo.

### Aesthetic Direction

Carry the main website's warm paper, orange, dark ink, Barlow Condensed headings, and Manrope supporting type into vector artwork. Use the existing ring and three streams as the visual motif. Popular open-source README banners, including StarRocks, are references for prominence and polish.

### Design Principles

- Make data movement the central visual idea.
- Express speed and efficient compute qualitatively, without benchmark numbers or competitor rankings.
- Preserve the existing logo geometry.
- Keep the headline legible at GitHub README widths.
- Ship a self-contained SVG with outlined lettering and an editable text source.
